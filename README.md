# ArtAround

### Istruzioni brevi:
- **Installazione**: Dovete avere installato Node.js e npm (controllate con `node -v` e `npm -v`).
- **Setup**: Clonate la repo e nella cartella `backend/` lanciate il comando `npm install`.
- **Configurazione**: Create un file `.env` dentro la cartella `backend/` e incollate le credenziali del database.
- **Avvio**: Per far partire il server scrivete `npm run dev`. Dovrebbe apparire il messaggio "Connesso a MongoDB" e "Server avviato sulla porta 3000".
